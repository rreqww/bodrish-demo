# BODRISH demo

Концептуальная демо-версия сайта бренда BODRISH.

## Запуск

Откройте `index.html` напрямую или запустите локальный сервер:

```powershell
npx serve .
```

Проект не содержит формы с реальной отправкой данных. Кнопка партнёрства ведёт на тот же Telegram-контакт, что и действующий сайт бренда.
